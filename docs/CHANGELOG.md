# Dark interface and repository publication

The basic light page was replaced with a charcoal interface, clearer typography and tabs, dark SVG canvases, restrained color accents, and a collapsible mobile navigation menu. All 18 diagrams, sources, design notes, hardware inputs, and workflow content are retained.

The update also fixes invalid standalone SVG line-break markup and stale calculator outputs after invalid input. Editable content is separated from generated assets, and structural/browser checks run before Pages publication.

The viewer remains documentation only; no live datacenter controls were added.
